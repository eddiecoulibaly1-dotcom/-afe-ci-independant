## 4. Tests automatisés existants ciblés

### COO planning
- Consolidation des chantiers par direction.
- Réconciliation d'un run cohérent.
- Réconciliation d'un run partiel sans faux diagnostic de corruption.
- Détection de mission/run mismatch, task missing, count mismatch.
- Registre DG stable.
- Approval clears required gate; rejection terminal.
- Replay idempotent et décision immuable.
- Validation des limites, structures, directions, priorité, deadline, duplications.

### Orchestration et worker
- Agent COO et directions actives/éligibles.
- Authentification Owner.
- Autonomie limitée aux niveaux configurés.
- Kill switch.
- Approbation obligatoire des actions sensibles.
- Plan persisté avant dispatch.
- Reprise avec plan et clés stables.
- Dispatch RPC atomique.
- Task result sync via RPC atomique.
- Lease token, expiration, fencing.
- Couverture exacte des tâches, status validés et livrable obligatoire pour done.
- Reconciliation read-only Run/Mission/Task.
