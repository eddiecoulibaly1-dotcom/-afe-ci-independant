# AFE-CI Debate Engine V1.1.4 — Quality hardening

## Scope
This release candidate hardens the strategic report, evidence audit, financial model and browser speech playback. It is isolated on \`hardening/debate-engine-v1-1-4\`; it is not promoted to production.

## Reasoning quality
- The strategic report now requires a structured decomposition, strongest case for and against, decisive disagreements, causal mechanisms, falsifiable hypotheses and reversal conditions.
- The debate's adjudication and the report's strategic recommendation are displayed as separate decisions.
- A provisional or unresolved debate cannot silently become a definitive GO.

## Evidence integrity
- A reference string supplied by an agent is no longer treated as verified evidence.
- Claims with a declared reference are marked \`pending_verification\` until a source has actually been opened and independently checked.
- Claims without a reference remain unsupported.
- Unverified high-impact references count as an evidence risk in the arbitration confidence and convergence policy.
- The current release does not yet provide a general-purpose external research crawler. The report must state this limitation and never fabricate source metadata.

## Deterministic financial model
The user may provide explicit inputs for:
- active users at months 12, 24 and 36;
- pessimistic, central and optimistic month-36 active-user scenarios;
- monthly revenue and variable cost per active merchant;
- monthly fixed costs, CAC and monthly churn;
- target active users and external funding ceiling.

The calculator derives contribution margin, break-even active users, CAC payback, indicative LTV, LTV/CAC, month-12/24/36 operating run-rate and a clearly qualified 36-month cumulative operating approximation.

Missing inputs remain null. The cumulative approximation assumes linear interpolation between the supplied milestones and excludes CAC, setup costs, taxes, financing and exceptional investment. It is not a cash-flow statement or audited forecast.

## Audio
- Browser speech is split into short chunks suitable for mobile engines.
- French voice selection is attempted but is not assumed to exist.
- Playback is resumed after queue reset; intentional cancel/interruption events are ignored.
- Unsupported engines and TTS errors display a diagnostic instead of a generic silent failure.
- Android device playback still requires a real-device test.

## Verification gates
1. TypeScript typecheck.
2. Unit tests for financial formulas, missing-value behavior and evidence states.
3. Vercel preview build.
4. Authenticated end-to-end report generation.
5. Android audio playback test.
6. Regression test of the original debate flow and Supabase persistence.

## Known limitations
- General external-source retrieval and source-content verification are not implemented by this release.
- The 36-month cumulative result is an operating approximation, not a cash-flow forecast.
- Browser speech support varies by Android browser, WebView and installed text-to-speech engine.
- No production promotion is authorized by this change.
